# Geospatial_analysis

Geospatial analysis of marine heatwaves (MHWs) and marine cold spells (MCSs)
from the surface to 1000 m depth in fishing zones of the Southeast Pacific
(Colombia, Ecuador, Peru, and Chile).

## Repository structure

| Folder | Content |
|---|---|
| `01_Presentations/` | Slides and figures for talks and progress reports |
| `02_Scripts/` | Processing, analysis, and visualization code |
| `03_Data/01_Thetao/` | Ocean potential temperature (thetao) fields |
| `03_Data/02_Argo/` | Argo float profiles |
| `03_Data/03_EEZ/` | Exclusive Economic Zone boundaries |
| `04_Manuscript/` | Manuscript drafts and supplementary material |

## Data

Raw data files are not tracked in this repository due to their size.
See each subfolder in `03_Data/` for sources and download instructions.
